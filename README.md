# 📦 Inventory Optimization & Sales Analysis Dashboard

An interactive **Streamlit-based data analytics dashboard** for analyzing **sales, purchases, and inventory data** to support **inventory optimization and business decision-making**.  
This project provides key KPIs, sales trends, ABC analysis, inventory turnover metrics, and vendor performance insights.

---

## 🚀 Project Overview

Managing large-scale inventory data using spreadsheets is inefficient and error-prone.  
This project leverages **Python, Pandas, and Streamlit** to:

- Analyze historical sales and purchase data
- Optimize inventory management
- Identify high-value products using ABC analysis
- Monitor inventory turnover and vendor performance
- Provide actionable insights through interactive dashboards

---

## 🧠 Key Features

✔️ Interactive Streamlit dashboard  
✔️ Sales trend visualization  
✔️ Inventory KPIs & metrics  
✔️ ABC classification of products  
✔️ Inventory turnover analysis  
✔️ Vendor performance analysis  
✔️ Cached data loading for performance  

---

## 📊 Key Metrics & Analysis

- **Total Sales Quantity**
- **Total Purchase Quantity**
- **Average Inventory**
- **Inventory Turnover Ratio**
- **Sales Trend Over Time**
- **ABC Analysis (A / B / C Categories)**
- **Top Vendors by Purchase Quantity**
